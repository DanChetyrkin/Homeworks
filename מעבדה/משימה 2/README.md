# מעבדה 2 — STM32: The Noisy Channel

תיקיית עבודה חדשה למעבדה 2, לפי [מאגר הקורס](https://github.com/YuvalHarary/Embedded_Lab_STM32).

## הקבצים

- `materials/`: עותקים של כל 11 הקבצים שנמסרו, ללא שינוי. `SHA256.json` מתעד את בדיקת ההעתקה.
- `firmware/partA/`: פרויקט חלק א׳. קובץ `lab02_partA.ioc` הוכן מהגדרות הכרטיס והשעון שבקובץ חלק ב׳: NUCLEO-G491RE, שעון 170MHz, יצוא CMake. הגדרות LPUART1 הוסרו מ-CubeMX כדי שהקוד של חלק א׳ יקבע אותן ישירות ברגיסטרים.
- `firmware/partB/`: עותק עבודה של `lab02_partB.ioc` ושל תוכנת המחשב `lab02_modbus.py`.
- `captures/A2/`, `captures/A3/`: מקום לתמונות המדידה בפועל.
- `notes/progress.md`: השלב הנוכחי ותוצאות שנבדקו.
- `STM32_Lab02.code-workspace`: פתיחת תיקיית העבודה ב-VS Code.

קובצי ה-C שנמסרו מכילים מקטעי `USER CODE`. משלבים כל מקטע באזור המתאים ב-`main.c` שנוצר ב-CubeMX; לא מחליפים בהם את כל הקובץ. המטלה דורשת לשמור בסיום כל משימה עותק מלא של `main.c` בשם שנקבע עבורה.

## אופן ההתקדמות

מתחילים בסעיף המעשי הראשון של חלק א׳. בכל פעם מבצעים סעיף אחד, בודקים תוצאה ורק אז ממשיכים. תוצאה צפויה אינה תוצאה שנמדדה. מסמנים סעיף כהושלם לאחר הבדיקות שנדרשות עבורו.

בעת ההכנה זוהה ST-LINK, ופורט ה-VCP שלו הוא `COM7`. יש לבדוק שוב את הפורט אם מחברים מחדש את הכרטיס.

הדגם שנמסר, Tektronix AFG3022B, הוא מחולל אותות. דגם האוסצילוסקופ למדידות A2 ו-A3 עדיין לא נמסר.

## מצב ההקמה

תיקיית העבודה ומאגר Git מקומי נוצרו. פרויקט חלק א׳ המלא נמצא ב-`firmware/partA/lab02_partA`.

A1 של מעבדה 2 נבנתה במצב Debug ונצרבה לכרטיס עם אימות תקין. הודעת האתחול `Lab 2 ready.` התקבלה ב-COM7. בדיקות לחיצות B1 ורגיסטרי הפינים עדיין ממתינות לבדיקה משותפת. עותק מלא של `main.c` למשימה נמצא ב-`submissions/A1/lab2partAtask1.c`.

לבנייה חוזרת במחשב הזה ניתן להשתמש ב-`build-partA.ps1`. לוג הצריבה ותוצאות האתחול נמצאים ב-`notes/`. שלבי ההמשך נרשמים בקובץ ההתקדמות לפי מה שבוצע בפועל.

המספור: **Lab 2** הוא מספר המעבדה (UART, Interrupts, Modbus RTU); **A1** היא המשימה הראשונה בחלק א׳ של אותה מעבדה. לאחר אימות A1 עוברים ל-A2, ובה מבצעים את מדידת ה-UART בסקופ.

## בנייה והרצה מעותק של Homeworks

פתח את `STM32_Lab02.code-workspace` ב-VS Code והפעל PowerShell בתיקיית המשימה. ב-Windows סקריפטי הבנייה מצפים לחבילות STM32Cube המקומיות GNU Tools for STM32 ‏14.3.1+st.2, ‏Ninja ‏1.13.2+st.1 ו-CMake ‏4.4.0+st.1. הפקודות `./build-partA.ps1` ו-`./build-partB.ps1` בונות את שני הפרויקטים בתיקיית `build/`.

להרצת קושחה מוכנה חבר כרטיס NUCLEO-G491RE דרך ST-LINK והרץ לדוגמה `./run-Lab02.ps1 -Mode B3`. סקריפט ההרצה משתמש ב-STM32CubeProgrammer ‏2.23.0, וב-Python 3.13 בבדיקות Modbus. הוראות לכל שלב שמורות בתיקיות `captures/`.
