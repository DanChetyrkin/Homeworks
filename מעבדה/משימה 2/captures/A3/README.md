# A3 במעבדה 2 — הרצה ותיעוד

שלחנו `0123456789` כרצף אחד ב-COM7, בקצב 115200 ובפורמט 8N1. קובץ ה-C המלא נמצא ב-`submissions/A3/lab2partAtask3.c`. שלוש הקושחות נצרבו ואומתו על הכרטיס.

| מצב | מה קורה בלולאה | תוצאה שנמדדה בכרטיס |
|---|---|---|
| A3a | Polling בלי השהיה | `0123456789` |
| A3b | Polling עם השהיה של 2,000,000 איטרציות והיפוך LD2 | `0` בשליחה הראשונה, פלט ריק בשנייה |
| A3c | פסיקת קליטה עם אותה השהיה | `0123456789` |

ב-A3b התו הראשון נשמר ב-RDR. התווים הבאים מגיעים לפני שהלולאה קוראת אותו ומדליקים את ORE. אחרי קריאת התו הראשון, RXNE מתאפס ו-ORE נשאר דולק. אחרי שתי השליחות קראנו דרך ST-LINK את `ISR=0x006000D8`, כלומר `RXNE=0` ו-`ORE=1`. קצב 115200 עם 8N1 נותן כ-86.8 µs לתו וכ-0.868 ms לכל הרצף. את ההשהיה בפועל נמדוד בסקופ ונשווה אליהם.

## הרצה מהירה ליד הסקופ

פתח PowerShell בתיקיית הפרויקט. הפקודה הבאה צורבת ומריצה את A3b, שהוא המצב לצילום ההשהיה.

```powershell
.\run-Lab02.ps1 -Mode A3b
```

1. חבר את תפס האדמה של גשוש CH1 ל-GND ואת קצה הגשוש ל-PA5, פין 11 במחבר CN10. ה-LED הירוק LD2 מחובר לאותו קו. [מפת הפינים של ST](https://www.st.com/resource/en/user_manual/um2505-stm32g4-nucleo64-boards-mb1367-stmicroelectronics.pdf#page=32)
2. הגדר CH1 בצימוד DC ובכניסת 1 MΩ, עם הנחתה תואמת לגשוש. התחל ב-1 V/div, ב-50 ms/div ובטריגר שפה סביב 1.6 V. התאם את סולם הזמן כדי לראות קצה עולה וקצה יורד סמוך.
3. הצב את סמני הזמן על **שני קצוות עוקבים**. הפרש הזמנים הוא זמן מעבר אחד בלולאה. שמור `04-pa5-delay.png` ובו שני הקצוות, `Δt` וסולמות הסקופ. זה צילום הסקופ הנדרש בעמ׳ 9 ובטבלה 2 בעמ׳ 18.

## תיעוד פלט ודגלים

לצילום פלט חוזר, סגור את Serial Monitor כדי לפנות את COM7 והרץ כל פקודה בנפרד. כל בדיקה שולחת בדיוק עשרה תווים, ו-A3b שולחת את הרצף פעמיים.

```powershell
.\run-Lab02.ps1 -Mode A3a -VerifyEcho
.\run-Lab02.ps1 -Mode A3b -VerifyEcho
.\run-Lab02.ps1 -Mode A3c -VerifyEcho
```

צילומי הפלט מההרצות של המשתמש שמורים בתיקייה זו כ-`01-polling.png`, `02-polling-delay.png` ו-`03-interrupt.png`. פלט הבדיקות שמור גם ב-`notes/a3_echo_results.txt`.

להדגמה ב-Watch, היצמד ל-A3b אחרי שתי השליחות והתחבר ל-Debugger בלי Reset. עצור את התוכנית והוסף `(LPUART1->ISR >> 5) & 1U` עבור RXNE ו-`(LPUART1->ISR >> 3) & 1U` עבור ORE. הצג את ISR בלי לפתוח את RDR, כי קריאה מ-RDR מאפסת את RXNE.
