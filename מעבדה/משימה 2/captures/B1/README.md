# B1 במעבדה 2 — הדלקת LD2 דרך Modbus

חבר את NUCLEO ל-USB של ST-LINK. אם COM7 פתוח ב-Serial Monitor, סגור את לשונית COM7. ב-PowerShell מתוך תיקיית הפרויקט הרץ:

```powershell
.\run-Lab02.ps1 -Mode B1
```

הפקודה צורבת את קושחת B1 ומריצה את תוכנת הקורס במצב `--write-only`. במהלך 20 הסבבים, LD2 הירוק מתחלף בין דולק לכבוי. בסוף הוא נשאר כבוי. צלם את הטרמינל עם שורות `write LD2=1: OK` ו-`write LD2=0: OK` ואת שורת הסיכום שמציגה `20 sends`, `0 requests with no reply` ו-`0 invalid replies`. שמור את התמונה בשם `01-modbus-write.png`.

כתובת הכרטיס היא 1. בקשת כתיבה `0x06` עם CRC תקין לרגיסטר 0 מכבה את LD2 אם הערך 0, ומדליקה אותו בכל ערך אחר. הכרטיס מחזיר עותק מדויק של הבקשה. בבדיקת החומרה, PA5 נקרא כגבוה אחרי כתיבת 2 וכנמוך אחרי כתיבת 0. בקשות עם כתובת שגויה, CRC פגום, רגיסטר לא נתמך, פונקציית קריאה או אורך שגוי לא קיבלו תשובה.

ה-callback מעביר הודעה שהסתיימה למאגר `message` ומפעיל שוב את הקליטה. הלולאה מעבדת את ההודעה ומפנה את המאגר. אם המאגר עדיין תפוס, ה-callback משליך את ההודעה החדשה. callback השגיאה מפעיל מחדש את הקליטה אחרי שגיאת UART.
