# A2 במעבדה 2 — דף עבודה ליד הסקופ

A2 נבנתה ונצרבה לכרטיס. הצילום `01-serial-a2.png` כבר מתעד את `Lab 2 ready.` ואת הספרות `4644` ב-COM7 בקצב 115200. קובץ המקור המלא להגשה נמצא ב-`submissions/A2/lab2partAtask2.c` בתיקיית הפרויקט. אם תידרש צריבה חוזרת, הקובץ `firmware/partA/lab02_A2.elf` הוא עותק של הקושחה שאומתה על הכרטיס.

## סדר ההרצה

1. חבר את הכרטיס ב-USB. אחרי הרצת A3, החזר את קושחת A2 עם `.\run-Lab02.ps1 -Mode A2` מתוך PowerShell בתיקיית הפרויקט. ב-VS Code פתח **Open Serial**, בחר **COM7** ו-**115200**, ולחץ B2 כדי לראות את הודעת האתחול.
2. חבר את תפס האדמה של גשוש CH1 ל-GND בכרטיס, למשל CN10 פין 20. חבר את קצה הגשוש ל-PC4, פין 34 במחבר CN10. [תרשים המחברים וטבלת הפינים של ST](https://www.st.com/resource/en/user_manual/um2505-stm32g4-nucleo64-boards-mb1367-stmicroelectronics.pdf#page=33)
3. הגדר את CH1 לצימוד DC ולכניסת 1 MΩ, עם הנחתה תואמת לגשוש. התחל ב-1 V/div וב-20 µs/div. כוון טריגר שפה יורדת מ-CH1 סביב 1.6 V והשאר לפחות 90 µs גלויים אחרי נקודת הטריגר.
4. כשהקו במנוחה, חמש **Single** ולחץ פעם אחת על B1. רשום את הספרה שהופיעה ב-Serial Monitor באותה לחיצה.
5. שמור `02-pc4-frame.png` עם כל מסגרת התו על CH1, כולל הקו הגבוה לפני ביט ההתחלה ואחרי ביט העצירה. כלול בצילום את סולמות הזמן והמתח. זה צילום הסקופ שהמטלה דורשת בעמוד 18, טבלה 2.

## מדידה ופענוח מאותה לכידה

- **זמן ביט.** כוון את הסמנים למרווח של ביט אחד בין שפות. אם אין מרווח כזה, מדוד מהשפה היורדת שמתחילה את `b6` עד השפה העולה של ביט העצירה וחלק ב-2. בכל ספרת ASCII, הביטים `b6` ו-`b7` נמוכים והביט `b5` גבוה. הצפי הוא כ-8.68 µs לביט.
- **התחלה עד עצירה.** מדוד מהשפה היורדת הראשונה עד השפה העולה שמתחילה את ביט העצירה. הצפי הוא כ-78.1 µs, תשעה ביטים. משך המסגרת המלאה, כולל ביט העצירה, הוא כ-86.8 µs.
- **קצב נמדד.** חלק 1 בזמן הביט בשניות.
- **פענוח.** אחרי ביט ההתחלה, קרא את שמונת ביטי הנתונים במרכז כל ביט, בסדר `b0` עד `b7`. חשב את הערך בהקסה והשווה לספרה שרשמת. לדוגמה, עבור `4` סדר השידור הוא `0 0 1 0 1 1 0 0`, והערך הוא `0x34`.

רשום את הספרה, זמן הביט, הזמן מהתחלה לעצירה, הקצב המחושב וערך ה-ASCII בפועל. אפשר לשמור גם `03-bit-time.png` ו-`04-start-to-stop.png` עם הסמנים כדי לתעד כל מדידה בנפרד.
