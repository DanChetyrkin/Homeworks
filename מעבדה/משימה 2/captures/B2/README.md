# B2 במעבדה 2 — קריאת רגיסטרים, חריגות ו-CRC

פתח PowerShell בתיקיית הפרויקט. אם COM7 פתוח ב-Serial Monitor, סגור את לשונית COM7. הרץ כל פקודה בנפרד ושמור צילום של הפלט שלה לפני המעבר לבאה.

| שלב | פקודה | מה לצלם |
|---|---|---|
| קריאה אחרי כתיבה | `.\run-Lab02.ps1 -Mode B2` | שתי דוגמאות של כתיבה וקריאה תואמות (`LD2=1` ו-`LD2=0`), `good=40 bad=0` בסבב 20 ושורת `[PC] done` עם 40 שליחות. שמור `01-read-registers.png`. |
| תשובות חריגה | `.\run-Lab02.ps1 -Mode B2 -B2Check Exceptions` | רגיסטר 9 מחזיר `exception code 2` ופונקציה `0x04` מחזירה `exception code 1`. שמור `02-exceptions.png`. |
| רעש ו-CRC | `.\run-Lab02.ps1 -Mode B2 -B2Check Noise` | הפקודה מאפסת את הכרטיס ומריצה `--errors 0.3 --seed 7`. צלם את `bad` בקריאה האחרונה ואת `with a wrong bit` בסיכום. בבדיקה על הכרטיס התקבלו 22 בשני המקומות, 62 שליחות בסך הכול ואפס תשובות חסרות או פסולות. שמור `03-crc-noise.png`. |

`good` עולה פעמיים בכל סבב רגיל כי הכתיבה והקריאה הן שתי בקשות. `bad` עולה על CRC פגום לפני בדיקת הכתובת, כי הביט שהשתבש יכול להיות בכתובת עצמה. הערך `bad` בתשובה משקף את מצב הכרטיס בזמן הקריאה האחרונה שהצליחה, וסיכום המחשב כולל את כל השליחות.

ב-115200 baud וב-8N1, זמן של 8 תווים לבקשה, 15 לתשובה ועוד 3.5 תווים של שקט אחרי כל מסגרת הוא כ-2.60 ms. חלון ההמתנה במחשב הוא 200 ms, כדי להשאיר מרווח לזמן העיבוד ולעיכובי USB ומערכת ההפעלה. `crc_sw` ו-`crc_hw` יישארו אפס עד B3.

קובץ ה-C המלא להגשה שמור ב-`submissions/B2/lab2partBtask2.c`. תוצאות הכרטיס שמורות ב-`notes/b2_reads.txt`, `notes/b2_exceptions.txt`, `notes/b2_noise.txt` ו-`notes/b2_edge_cases.txt`.
